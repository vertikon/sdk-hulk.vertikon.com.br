# SDK Hulk v0.9.1

- Mantém as dependências de segurança do commit `0774842`.
- No boot, cria `EVENTS` apenas se ausente. Em uma stream existente, acrescenta
  `events.>` quando necessário, preservando os demais subjects e configurações.
- Inicializa OpenTelemetry apenas com `OTEL_COLLECTOR_URL` ou
  `OTEL_EXPORTER_OTLP_ENDPOINT` preenchido. Sem endpoint, não cria exportadores
  nem usa implicitamente `localhost:4317`.

Atualização dos consumidores:

```sh
go get github.com/vertikon/sdk-hulk.vertikon.com.br@v0.9.1
go mod tidy
```

Validação local em 2026-10-05: build, vet, staticcheck e suíte completa passaram,
incluindo NATS Server 2.12.0 isolado. Os testes de regressão falharam no código
`0774842`: fallback para localhost e sobrescrita dos subjects, limites e retenção
da stream. Com as correções, passaram. `govulncheck` não encontrou vulnerabilidades
alcançáveis (uma no conjunto de módulos requeridos, sem chamadas identificadas).
Isso não constitui validação do boot do agente em produção.
